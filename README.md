# Algoritmos-e-pensamento-computacional
Aula de desenvolvimento de algoritmos

Calculadora — 20 Operações

Projeto de uma calculadora capaz de realizar 20 operações matemáticas, desenvolvido como atividade colaborativa no GitHub.

Sobre o projeto

A calculadora foi criada para realizar diferentes operações matemáticas de forma simples e rápida. O projeto foi dividido entre os participantes, sendo que cada integrante ficou responsável por 4 operações, totalizando 20 operações.
