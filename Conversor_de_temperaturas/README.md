🌡️ Conversor de Temperaturas em C

Um programa simples desenvolvido em C para realizar conversões de temperatura entre Celsius (°C), Fahrenheit (°F) e Kelvin (K).

📌 Funcionalidades

O programa permite converter:

Celsius → Fahrenheit
Celsius → Kelvin
Fahrenheit → Celsius
Fahrenheit → Kelvin
Kelvin → Celsius
Kelvin → Fahrenheit
🛠️ Tecnologias utilizadas
Linguagem: C
Compilador: GCC
📚 Conceitos praticados

Este projeto foi desenvolvido para praticar conceitos básicos da linguagem C, como:

Variáveis
Tipos de dados
scanf() e printf()
if e else if
Operadores lógicos
Operações matemáticas

🎯 Objetivo

Projeto desenvolvido com o objetivo de praticar lógica de programação e os fundamentos da linguagem C.
